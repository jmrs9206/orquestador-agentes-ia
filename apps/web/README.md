# Next.js Frontend App

This directory is designated for the Next.js frontend application.

## Stack
- Framework: Next.js
- Library: React
- Language: TypeScript
- Styles: Tailwind CSS
- Unit Testing: Vitest
- E2E Testing: Playwright

## Structure (Proposed)
- `src/components`: Reusable UI presentation components.
- `src/app`: Application router pages.
- `src/services`: Service client for consuming the backend REST API.
- `src/types`: TypeScript definitions.
